Header Examples

Examples of header components following the Alberta Design System.

Basic Header

A simple application header with just the Government of Alberta branding.

Code:

</goab-app-header>

Header with Service Name

  heading="Service Name">

Usage Guidelines

When to use different header configurations:

  • Basic Header: Simple applications or landing pages with minimal navigation
  • Header with Service Name: Applications and services that need clear identification
  • Header with Navigation: Applications with multiple sections or pages
  • Header with Dropdown Menus: Complex applications with many features and user account management
  • Header with Microsite Header: Development, testing, or specialty applications that need environment indicators

Best Practices:

  • Always link the Government of Alberta logo to the main government website
  • Keep navigation items focused and well-organized
  • Use appropriate breakpoints for your content layout
  • Test mobile navigation thoroughly
  • Include a sign-in link for authenticated applications
  • Use microsite headers to clearly indicate environment (Alpha, Beta, etc.)
  • Ensure header content is accessible and keyboard navigable

Accessibility Considerations:

  • All navigation links should be keyboard accessible
  • Dropdown menus should work with screen readers
  • Color contrast should meet WCAG guidelines
  • Mobile menu button should have appropriate aria labels
